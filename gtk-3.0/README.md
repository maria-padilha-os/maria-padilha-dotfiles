# GTK 3 and GTK 4 settings

`gtk-3.0/settings.ini` and `gtk-4.0/settings.ini` are the only tracked GTK
settings files. They select `adw-gtk3-dark`, Papirus-Dark icons, Noto Sans 10
and the dark preference so Thunar and the other GTK applications match the
Maria Padilha palette.

The colour sheets in these directories (`gtk.css` and `thunar.css` in both
`gtk-3.0` and `gtk-4.0`) are generated by `padilha-theme` in
`maria-padilha-de`. They are not tracked here, are overwritten by the theme
engine, and must not be edited. `padilha-dots` links only the two `settings.ini`
files, so applying a theme never writes into this checkout.

See [`../thunar/README.md`](../thunar/README.md) for the complete generated-file
list and the Thunar behaviour.
